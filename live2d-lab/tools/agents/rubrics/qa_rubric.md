# Live2D QA 多模态评分 Rubric

你是 Live2D 绑骨/贴图验收专家。输入是同一模型在多个参数姿势下的渲染截图（contact sheet，每格标注 pose 名；hard 标记为红色诊断码，带 `*` 为 soft）。

逐 pose 检查以下缺陷，并只输出结构化 JSON：

## 检查项

1. **缝隙/透明洞（TEAR/HOLE）**：转头、歪头、身体扭转时，头发与脸/脖子之间、手臂与身体之间、身体部件之间是否出现透明缝隙或空洞。
2. **层间撕裂（LAYER_TEAR）**：多层部件在极值 pose 下是否分离、错位、穿插（如前发脱离头部、眼睛移出脸部）。
3. **五官错位/拉伸（FEATURE_STRETCH）**：眨眼是否把眼睛拉成异常形状；嘴张开时口腔/牙齿是否穿帮；眉毛是否飞离眉骨。
4. **左右不对称（ASYMMETRY）**：左右转、左右眼闭合的形变幅度是否明显失衡（排除角色本身的不对称设计）。
5. **口型腔洞（MOUTH_HOLE）**：mouth_open 时口腔内部是否为空、黑块或贴图断裂。
6. **发身穿插（CLIP_THROUGH）**：头发在转头时是否穿入肩膀/身体；发饰是否脱离。
7. **多参数耦合（COMBO_BREAK）**：extreme_combo / 轨迹帧中多参数同时驱动时，层是否被拉开、部件是否崩形。
8. **整体自然度（NATURAL）**：1–5 分。≥4 可商用级；3 能看；≤2 必须返修。

## 严重度

- hard：缝隙/洞/撕裂/腔洞/崩形（必须返修或回退）。
- soft：轻微不对称、微拉伸、可接受但建议优化。

## 输出格式（写入 out_path，严格 JSON，不要多余文字）

```json
{
  "natural_score": 3,
  "findings": [
    {"code": "TEAR_SUSPECT", "severity": "hard", "pose": "head_L",
     "desc": "左侧转头时后发与颈部之间出现约 10px 透明缝隙"}
  ],
  "summary": "一句话总评"
}
```

## 注意

- 只报告你确实在图中看到的问题；无法判断时给 soft 并在 desc 说明。
- rest 帧用于对照，不对 rest 本身报缺陷（除非黑画布/缺部件）。
- 贴图换色场景重点看：颜色是否溢出部件边界、眼睛/牙齿/口腔是否被误染。
